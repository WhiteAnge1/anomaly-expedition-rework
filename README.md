# RVM Sorties Rework by White_Angel

Версия: **0.2.0-alpha**. Это отдельный MO2-мод для фактической сборки GRA 2.5 с активным слоем `GRA Bolt`. Исходные моды не изменяются.

## Установка

1. Установить архив через MO2 как обычный мод.
2. Назвать мод `RVM Sorties Rework by White_Angel` (FOMOD предложит это имя).
3. Поставить его **выше по приоритету конфликтов** относительно `GRA Bolt`, Arrival и PAW. Мод не заменяет их Lua-файлы или `map_spots.xml`; для map spot используется DXML.
4. Запустить игру полностью заново. Для первой проверки оставить `debug_log = true`.
5. Настройки находятся в `gamedata/configs/plugins/rvm_sorties_rework.ltx`.

Удаление/отключение мода возвращает исходное поведение: единственные LTX-переопределения относятся к описаниям маршрутных листов, а вся механика подключается отдельными скриптами.

## Что реализовано в альфе

- перехват только `raid_anomalys.spawn_artefact_in_zone`; ванильные артефакты и Arrival не сканируются и не маркируются;
- отдельный невидимый якорь для центра каждой настоящей области; положение артефакта не передаётся карте или PAW;
- стохастический расчёт числа ложных областей и перенормировка включённых весов;
- типы `enemy`, `loot`, `empty`, внешне использующие один и тот же map spot;
- безопасная задержка до фиксации фактической позиции actor;
- мутантская засада из редактируемого белого списка, со штатным `spawn_block_radius` РВМ + запасом, проверкой дистанции, направления взгляда и близости аномалий;
- контейнер с различными предметами, медицинским броском и редким слотом;
- редкий артефакт выбирается из актуальных таблиц РВМ: Поляна — весь мусор и T1, Тёмная лощина — T1 и T2, Мёртвый город — T2 и T3;
- созданный в контейнере артефакт передаётся штатной сохраняемой очереди `raid_artefacts`, поэтому получает родной случайный класс и мутации РВМ;
- `stash_mode = anomaly/scouting/disabled` без одновременного создания одного набора тайников;
- удаление настоящей области при подборе игроком и опционально NPC;
- сохранение состояния и восстановление отсутствующих map spots после загрузки;
- очистка якорей, созданных существ, контейнеров и служебного состояния при смене уровня;
- подробный журнал с префиксом `[RVM Sorties Rework]`.

## Важные ограничения альфы

- X-Ray задаёт размер map spot в UI-пикселях, а не в мировых метрах. Поэтому круг — честная приблизительная область из размерной корзины, но не геодезически точная окружность радиуса из конфига. Фактическая логика размещения использует метры.
- Проверка «не виден игроку» консервативно использует направление камеры и дистанцию. Доступного надёжного Lua raycast до произвольной точки в исследованном коде не найдено; поэтому это требуется проверить в игре.
- Альфа создаёт только мутантские засады. Человеческие squad-секции намеренно не включены до игровой проверки фильтрации тяжёлых костюмов/рангов.
- Открытый контейнер не удаляется немедленно: callback снимает область и якорь, а сам box удаляется при выходе. Это предотвращает инвалидирование открытого окна инвентаря.
- PAW по коду принимает ID выбранного map spot. Якорь `raid_shelter_gag` относится к допустимым физическим объектам в текущей конфигурации PAW, но правый щелчок по крупному кругу на разных масштабах требует игровой приёмки.
- Обычные предметы контейнера используют равные веса внутри категории. Вероятность редкого слота и доля артефактов в нём настраиваются отдельно; внутри разрешённого артефактного пула выбор равновероятный.

## Быстрый тест

1. Включить `debug_log = true`.
2. Получить и использовать маршрутный лист аномальной экспедиции (`infected`).
3. В логе найти `captured raid artifact`, затем строки `create type=...`.
4. Проверить, что ID настоящих областей совпадают только с ID из захвата функции рейдового спавна.
5. На карте нажать правой кнопкой по центру круга и поставить PAW-маршрут: он должен указывать на независимый якорь.
6. Поднять артефакт — соответствующая область должна исчезнуть.
7. Сохраниться и загрузиться внутри вылазки — число `create` не должно увеличиться, отсутствующие spots восстанавливаются.
8. Выйти с локации — в логе должна появиться строка `cleanup`.
9. Повторить для разведывательной вылазки: исходные точки разведки и разведданные сохраняются, дополнительно появляется один исходный тайник.
10. Для проверки редких наград временно поднять `rare_slot_chance` и `rare_artifact_chance` до 100, затем проверить разрешённые тиры, класс, мутации и сохранение/загрузку до открытия контейнера. После теста вернуть значения 4 и 70.

Для принудительных тестов используйте `debug_force_decoy_type`, `debug_force_tier` и `debug_cleanup_current_sortie` в конфиге. После проверки обязательно верните их в `off`, `0`, `false`.

Подробности исследования: `docs/RESEARCH.md`. Матрица приёмки: `docs/TESTING.md`.
