# Anomaly Expedition Rework 0.3.0-rc3

`0.3.0-rc3` — исправленный устанавливаемый prerelease для полевой приёмки. Он заменяет superseded `rc2`; игровая логика вылазок относительно `rc2` не менялась.

## Исправлено

- русский MCM-файл приведён к фактическому формату сборки: Windows-1251 без BOM с правильной XML declaration;
- добавлены точные ключи, которые Anomaly MCM 1.7.2 вычисляет для корневого меню, подразделов и значений списков;
- устранены raw `ui_mcm_menu_*`, `*_lst_*` и mojibake;
- весь пользовательский текст установщика FOMOD переведён на русский;
- тесты теперь проверяют фактическую кодировку, BOM/declaration, типичный восстанавливаемый mojibake и полное разрешение RU+EN ID.

## Установка

1. Убедиться, что включён Anomaly MCM 1.7.2.
2. Установить ZIP через MO2 новой отдельной записью, не объединяя его с `rc2`, alpha или dev-копией.
3. В FOMOD нажать обычную кнопку **«Установить»**. Штатную кнопку MO2 **«Вручную»** для стандартной установки не нажимать.
4. Оставить имя `[Геймплей] Anomaly Expedition Rework by White_Angel v0.3.0-rc3` и поставить мод выше по приоритету конфликтов относительно GRA Bolt, Arrival и PAW.
5. Полностью перезапустить игру. Новая игра не нужна; настройки применяются со следующей новой вылазки.

## Короткая визуальная проверка

1. Открыть FOMOD: шаг, группа, единственный профиль и описание должны быть по-русски.
2. Открыть `Настройки → MCM → Переработка аномальных вылазок`.
3. Убедиться, что название, все десять разделов, подписи и tooltip читаются по-русски без `Р.../С...`.
4. Открыть список маршрутизации тайника: должны отображаться `Разведывательный`, `Аномальный`, `Отключён`, а не технические ключи.
5. Нажать Reset/Defaults и затем начать новую infected-вылазку для основной полевой приёмки.
