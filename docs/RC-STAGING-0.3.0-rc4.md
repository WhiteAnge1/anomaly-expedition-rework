# RC staging 0.3.0-rc4

`rc4` предназначен только для узкого воспроизведения возможного смещения мутантского отряда после сохранения и загрузки в Тёмной лощине.

## Границы изменения

- добавлено только наблюдение за принадлежащими AER вражескими squad и их участниками;
- снимки пишутся при создании, непосредственно перед сохранением, при восстановлении состояния, на первом update после загрузки и через 5/15/30 секунд;
- журнал содержит session/sortie nonce, anchor/squad/commander/member ID, server/online position, level/game vertex, расстояния до actor и якоря, delta относительно pre-save, smart/target и признаки `same_id`, `created_this_session`, `owned_by_rework`;
- каждая строка явно содержит `position_write=false`;
- диагностический блок не создаёт и не удаляет NPC, не телепортирует их и не записывает position/vertex;
- ошибка наблюдения отключает только эту диагностику до перезапуска скрипта, не механику вылазки;
- баланс и распределение ложных областей Тёмной лощины остаются `2/3/4 = 33/34/33`.

## Обязательные доказательства перед публикацией

- изолированный timeline-тест проходит на Lua 5.1, LuaJIT 2.0 и LuaJIT 2.1 и подтверждает ровно один снимок 0/5/15/30 секунд;
- policy-тест запрещает в диагностическом блоке `teleport`, `set_position`, position/vertex assignment, create/release;
- main chunk остаётся в доказанном пределе X-Ray `198/198`;
- полный статический suite, MCM/кодировки, FOMOD и проверка распакованного архива проходят;
- две чистые сборки одного HEAD дают байт-в-байт одинаковый ZIP;
- GitHub публикуется как prerelease, предыдущий RC помечается superseded;
- активная MO2-сборка и HeatVision не изменяются.
