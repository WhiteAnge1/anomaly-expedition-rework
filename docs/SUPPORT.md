# Сообщение об ошибке

Перед созданием GitHub issue проверьте, что включена только одна версия AER и игра была полностью перезапущена после установки.

Скопируйте шаблон и заполните известные поля:

```text
Версия AER:
Версия/профиль GRA 2.5 и renderer:
Профиль FOMOD AER:
Локация и тип вылазки:
Новая вылазка или загруженное сохранение:
Какие exact/debug/forced параметры изменены:

Ожидалось:
Произошло:
Шаги воспроизведения:

Сохранение до ошибки приложено: да/нет
xray log приложен: да/нет
Watcher session log приложен: да/нет
SHA-256 приложенных файлов:
Другие активные моды, затрагивающие вылазки/PAW/MCM:
```

Не публикуйте приватные данные, токены, пароли и полный список локальных путей без необходимости. Для runtime-проблем приложите обычный `<папка игры>\appdata\logs\xray_<имя>.log` со строками `[Anomaly Expedition Rework]`. `tools\watch_live_log.cmd` не входит в Release ZIP: это необязательный инструмент тестировщика из исходного репозитория. Скриншоты карты полезны только вместе с последовательностью действий и логом.
