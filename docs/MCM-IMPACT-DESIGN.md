# MCM impact and design — post-0.3.0-rc1

## Исследованный фактический API

Проверена установленная сборка `E:\GRA2.5\MO2\mods\[Тех_настройки] Anomaly-MCM 1.7.2`: `on_mcm_load()` возвращает дерево `id/sh/gr`, значения читаются через `ui_mcm.get("namespace/path")`, а `ui_mcm.get()` запрещён во время gathering. MCM 1.7.2 автоматически ищет подпись `ui_mcm_<path>` и tooltip `ui_mcm_<path>_desc`. Сверены реальные реализации GRA Bolt, Dodge, PAW и Arrival.

## Архитектура

- `rvm_sorties_mcm.script` только объявляет 56 controls и публичные defaults; debug, forced и deprecated rescue отсутствуют.
- `rvm_sorties_config.script` — единственный effective settings layer. Он защищённо читает MCM через `pcall`, валидирует типы/границы и падает обратно на LTX при отсутствии, gathering, исключении или неверном значении.
- На границе новой вылазки runtime создаёт `state.settings_snapshot`, активирует его до генерации и сохраняет штатным callback. Повторные callbacks не переснимают настройки. Load восстанавливает снимок; старый save мигрирует один раз. Cleanup очищает снимок.
- Ряды quality и artifact-count нормализуются до 100 методом largest remainder; нулевая/невалидная сумма использует LTX целиком. Zone-count веса остаются положительными относительными весами. Нулевой итог включённых типов decoy возвращает весь набор весов к LTX. Деления на ноль нет.
- Artifact pool context пересобирается ровно после активации нового/загруженного снимка, поэтому profile и quality weights согласованы с остальной вылазкой.

## Влияние и миграция

MCM выше LTX по приоритету, поэтому ручные значения LTX для представленных controls не действуют при доступном MCM. Reset/Defaults совпадает с LTX baseline. Старые отладочные LTX сохраняют смысл. FOMOD сокращён с 136 полных копий LTX до одного Recommended baseline; конкурирующих overlay больше нет.

Изменение настроек во время рейда намеренно не применяется частично. Все публичные gameplay controls имеют русскую и английскую подсказку с эффектом, зависимостями, default, диапазоном/вариантами и моментом применения.
