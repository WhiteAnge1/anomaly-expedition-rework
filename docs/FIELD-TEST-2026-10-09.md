# Полевой тест: Поляна, 2026-10-09

Источник диагностики: `test-artifacts/2026-10-09-pole-first-run/xray_maksi.log` из рабочей папки основного агента.

## Что подтвердилось

- Перехвачен запуск `infected` на `y04_pole`.
- Захвачены ровно четыре ID рейдовых артефактов: `3084`, `6198`, `6200`, `6191`.
- Созданы четыре настоящие и две ложные loot-области; посторонние артефакты не маркировались.
- Три настоящие области закрылись с `reason=actor_pickup`, одна осталась активной.
- После сохранения/загрузки повторного создания областей не произошло.
- При смене уровня выполнена очистка шести областей.
- Все десять штатных попыток аномального тайника были подавлены, как требует `stash_mode = scouting`.

## Найденные проблемы и исправления

- Русская string table переведена из UTF-8 в Windows-1251, соответствующую фактическим таблицам сборки.
- Физический `raid_shelter_gag` заменён в роли постоянного map-якоря на PAW `script_zone`; действие «Перейти» больше не должно появляться.
- Невидимый голый `inventory_box` заменён связкой из штатной видимой модели `raid_small_stash_1..17` и наложенного inventory box.
- Отсутствующие во время выполнения `simk_card` и `artifact_container` удалены из таблиц наград; добавлена статическая проверка внешних секций и сохранена runtime-фильтрация через `ini_sys:section_exist`.
- Форматы `%.1f`, не поддерживаемые `printf` X-Ray, заменены безопасными строковыми значениями.
- Визуальный размер круга отделён от логического радиуса и зафиксирован от роста при zoom.
- Для Поляны установлен `max_false_zones = 1`; все настоящие области сохраняются.

## Следующий тест

1. Полностью перезапустить игру после обновления файлов мода.
2. В конфиге временно установить `debug_force_decoy_type = loot`, остальные debug-параметры оставить `0/false`, а `debug_log = true`.
3. Начать новую аномальную вылазку на Поляну. Старое сохранение можно загрузить только для проверки совместимости, но результат генерации оценивать на новой вылазке.
4. Убедиться, что строка `decoy plan` сообщает `cap=1` и создано не более одной ложной области сверх всех настоящих.
5. На карте проверить компактный одинаковый размер кругов на разных масштабах.
6. Правой кнопкой по кругу проверить отсутствие «Перейти» и корректную постановку PAW-маршрута на центр.
7. Найти ложную область: в центре должна быть видимая модель тайника. Открытие должно показать предметы и дать в логе `reason=container_opened`; круг должен исчезнуть, окно инвентаря — остаться рабочим.
8. Проверить лог на отсутствие `config section missing`, ошибок форматирования и Lua/X-Ray ошибок с префиксом мода.
9. Вернуть `debug_force_decoy_type = off` после теста.
