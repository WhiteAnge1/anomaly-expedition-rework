# Anomaly Expedition Rework 0.3.0-rc7

Исправлено исчезновение незавершённой приблизительной зоны AER после автоматического закрытия, ручной отмены или переноса маршрутной метки Personal Adjustable Waypoint.

Новые якоря зон принадлежат AER и больше не регистрируются как временные `script_zone` PAW. Открытые зоны из RC6 безопасно меняют только потерянный или PAW-owned anchor; уже созданные артефакты, тайники и мутантские отряды сохраняются без повторного spawn. Закрытые зоны не восстанавливаются.

RC6 scripted self-target для мутантских засад сохранён без изменений. Сторонние файлы PAW не изменяются.

Полевой gate пройден: подтверждены пеший PAW auto-clear, переход к waypoint, ручная отмена/перенос и штатное закрытие зоны. Повторного содержимого или воскресшей закрытой зоны не обнаружено.

## Установка и обновление

1. Скачать `Anomaly-Expedition-Rework-0.3.0-rc7.zip` и соседний `.sha256` из этого GitHub Release.
2. Установить ZIP через FOMOD как новую отдельную запись MO2 с предложенным именем `[Геймплей] Anomaly Expedition Rework by White_Angel v0.3.0-rc7`.
3. Отключить прежнюю RC/alpha-запись AER; не объединять каталоги и не копировать старый LTX поверх RC7.
4. Поставить RC7 выше по приоритету конфликтов относительно GRA Bolt, Arrival и PAW, затем полностью перезапустить игру.

Новая игра не нужна. Уже полученный маршрутный лист остаётся ключом входа, а новый контент создаётся при переходе на локацию вылазки. Открытая RC6-зона совместима с миграцией anchor RC7; для максимально чистого обновления рекомендуется начинать следующую новую вылазку.

## Проверка SHA-256

```powershell
(Get-FileHash -Algorithm SHA256 -LiteralPath '.\Anomaly-Expedition-Rework-0.3.0-rc7.zip').Hash
```

Хеш должен совпасть с `Anomaly-Expedition-Rework-0.3.0-rc7.zip.sha256`.

## Известные ограничения

- Поддерживается фактический стек GRA 2.5/GRA Bolt, Rojok Artifact System, Arrival, PAW и Anomaly MCM 1.7.2; другие сборки не проверены.
- Размер круга в PDA задаётся UI-пикселями и меняется с масштабом карты; это приблизительная область, а не метрическая окружность.
- Две точные artifact-иконки с одинаковыми X/Z могут визуально перекрываться.
- Открыты отдельные вопросы [#3](https://github.com/WhiteAnge1/anomaly-expedition-rework/issues/3) и [#5](https://github.com/WhiteAnge1/anomaly-expedition-rework/issues/5); исправленный PAW anchor defect отслеживался в #1.
