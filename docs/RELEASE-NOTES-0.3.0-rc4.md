# Anomaly Expedition Rework 0.3.0-rc4

`0.3.0-rc4` — диагностический prerelease для проверки возможного смещения мутантского отряда после save/load. Это наблюдение, а не исправление: мод не меняет сохранённые или текущие позиции NPC.

## Добавлено

- независимый session nonce и сохраняемый sortie nonce для сопоставления строк до и после загрузки;
- снимки каждого участника AER-squad при создании, перед сохранением, при load restore, на первом update и через 5/15/30 секунд;
- server/online position, level/game vertex, расстояния до actor и якоря, pre-save delta, smart/target и ID якоря, squad, командира и участника;
- явные признаки `same_id`, `created_this_session=false`, `owned_by_rework=true`, `position_write=false` после загрузки;
- rate limit: каждый временной этап одного отряда выводится не более одного раза;
- fail-closed: исключение отключает только squad-диагностику и оставляет игровой процесс без изменений;
- исполняемый Lua 5.1/LuaJIT regression и статический запрет любых position/vertex writes, teleport, create/release в диагностическом блоке.

Игровой баланс не менялся. В частности, распределение числа ложных областей Тёмной лощины остаётся `2/3/4 = 33/34/33`.

## Установка

1. Установить ZIP через MO2 новой отдельной записью, не объединяя со старой или dev-копией.
2. Оставить имя `[Геймплей] Anomaly Expedition Rework by White_Angel v0.3.0-rc4`.
3. Поставить мод выше по приоритету конфликтов относительно GRA Bolt, Arrival и PAW.
4. Полностью перезапустить игру. Новая игра не нужна.

## Узкий тест

1. Оставить общий debug/техническую консоль мода выключенными, включить только точные метки врагов.
2. Начать infected-вылазку в Тёмную лощину с немедленным созданием enemy-зоны.
3. Подойти к одному отряду, сделать скриншот и сохранение, затем загрузить его.
4. Сделать скриншоты сразу после загрузки и примерно через 5, 15 и 30 секунд, не провоцируя лишнее перемещение отряда.
5. Завершить вылазку обычным выходом и сохранить полный X-Ray log.
