# Anomaly Expedition Rework 0.3.0-rc9

RC9 исправляет совместимость с Personal Adjustable Waypoint при подборе связанного с вылазкой артефакта.

## Что исправлено

Если PAW сохранял route или persistent pin между вылазками, в редком переходном кадре подбора X-Ray мог уже удалить ALife server object, используемый PAW для расчёта экранной координаты, но ещё оставить соответствующий client object. PAW обращался к отсутствующему server object и завершал игру Lua fatal `se_obj nil`.

RC9 безопасно пропускает расчёт экранной координаты только для этого переходного кадра. Пользовательский route/pin не удаляется, обычная логика PAW не меняется, а файлы PAW мод не заменяет.

Исправление прошло исходную полевую последовательность с точными метками, сохранёнными route/pin, переходом между вылазками, отключением exact markers и последующим pickup. Также прошли pickup без PAW и два дополнительных pickup с route/pin на приблизительных областях. Связанные области AER закрылись штатно, прежний fatal не повторился.

## Установка и обновление

1. Скачать `Anomaly-Expedition-Rework-0.3.0-rc9.zip` и соседний `.sha256`.
2. Установить ZIP через MO2 как новую отдельную запись, оставив предложенное FOMOD-имя `[Геймплей] A_Exp_R by White_Angel v0.3`.
3. Отключить RC8 или более старую запись AER; не объединять каталоги разных версий и не копировать старый LTX поверх RC9.
4. Сохранить прежний порядок приоритетов относительно GRA Bolt, Arrival и PAW, затем полностью выйти из игры и запустить её снова.

Новая игра не нужна. Уже полученный маршрутный лист остаётся пригодным: содержимое создаётся при входе на локацию вылазки. Изменение настроек внутри уже активной вылазки не перестраивает её задним числом и применяется к следующей новой вылазке.

## Проверка архива

```powershell
(Get-FileHash -Algorithm SHA256 -LiteralPath '.\Anomaly-Expedition-Rework-0.3.0-rc9.zip').Hash
```

Ожидаемый SHA-256: `43A13A8A2DF36C298F4B98C6A84C561AAB7F7B55AF33C36AB737E85B0633C641`. Он должен совпадать со строкой в `Anomaly-Expedition-Rework-0.3.0-rc9.zip.sha256`.

## Известная граница

PAW сохраняет собственную координату карты рядом с визуальной меткой, а не object-level ссылку на маркер AER. Небольшое визуальное смещение пользовательской route/pin относительно значка ожидаемо и не означает потерю связанной области.

Один отдельный нативный `AnomalyDX11.exe` access violation наблюдался в более раннем запуске, но не повторился после полного перезапуска на двух контролируемых pickup и не сопровождался Lua fatal. Без воспроизводимости он не классифицирован как регрессия этого исправления.
